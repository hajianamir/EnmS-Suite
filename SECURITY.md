# Security Policy & Vulnerability Reporting

## Supported Versions
VerdantOS platform security updates are supported for the latest main branch.

| Version | Supported |
| :--- | :--- |
| Main (Development) | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Security Vulnerability
To report a security vulnerability, please submit a **GitHub Private Security Advisory** via the repository Security tab at [https://github.com/hajianamir/EnmS-Suite/security/advisories](https://github.com/hajianamir/EnmS-Suite/security/advisories).

Alternatively, if private security advisories are unavailable, email the VerdantOS Security Engineering Team at `security@verdantos.com`.

Please include:
1. Description of the vulnerability and potential impact.
2. Step-by-step reproduction instructions or proof-of-concept payload.
3. Affected components or microservices.

We will acknowledge receipt within 24 hours and provide a remediation timeline within 5 business days.
